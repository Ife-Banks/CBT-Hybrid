Interactive demo · sample data

School CBT Platform

Teachers build exams in the cloud. Students write them in the computer lab with no internet needed. Results sync up, teachers review and release, parents see them on their phones.

How the two halves fit together

TEACHERS / ADMIN / PARENTS  (any device, internet)
                │  HTTPS
                ▼
┌──────────────────────────────────────────────┐
│ CLOUD                                        │
│   Next.js portals  ◄──►  NestJS API          │
│                    PostgreSQL · Redis · S3    │
└──────────────▲───────────────────────────────┘
               │  HTTPS, outbound from school only
               │   ▼ exam packs + roster   ▲ results
┌──────────────┴───────────────────────────────┐
│ SCHOOL LAB  (works with no internet)         │
│   Exam server PC (Windows service)           │
│     NestJS · SQLite · static exam client     │
│          ▲  plain HTTP over the lab LAN      │
│   Lab PCs: browser only, nothing installed   │
